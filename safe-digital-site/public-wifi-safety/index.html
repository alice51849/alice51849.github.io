公共 Wi-Fi 安全嗎？咖啡廳、機場、飯店上網前要知道的 5 件事

公共 Wi-Fi 的風險常被誇大，但也確實存在。了解真正的風險在哪，就知道該怎麼防。

現在的公共 Wi-Fi 有多危險？

大部分網站與 App 都已經使用 HTTPS 加密連線，就算有人在同一個 Wi-Fi 上監看，也看不到你輸入的密碼或訊息內容。真正的風險主要是下面這幾種：

  1. **假熱點：**有人架設一個名字很像的 Wi-Fi，例如「Airport_Free_WiFi」，引導你連上，再搭配假的登入頁面騙資料。
  2. **看得到你連去哪裡：**雖然看不到內容，但同網路的管理者可以知道你連到哪些網站。
  3. **舊裝置或沒更新的 App：**沒有加密的舊服務，在公共網路上的確可能被看到內容。

上公共 Wi-Fi 的 5 個習慣

1. 確認 Wi-Fi 名稱

向店家或櫃台確認正確的網路名稱。同時出現好幾個很像的名稱時，要特別小心。

2. 不在跳出的網頁輸入帳號密碼

連上 Wi-Fi 時跳出的登入頁面，如果要求你用 Google、Facebook 帳號登入或輸入信用卡資料，先停下來想一想。

3. 注意瀏覽器的警告

如果瀏覽器出現「這個連線不是私人連線」之類的憑證警告，不要按繼續，直接離開這個網路。

4. 用完就「忘記這個網路」

避免手機日後自動連上同名的假熱點。iPhone：設定 → Wi-Fi → 點網路旁的 ⓘ →「忘記此網路設定」。

5. 保持手機和 App 更新

很多安全問題都是靠更新修補的。

什麼時候值得用 VPN？

如果你經常在咖啡廳、共享辦公室、飯店工作，或是不希望網路管理者知道你連去哪些網站，VPN 能把所有連線包進加密通道，是值得的投資。

常見問題

用公共 Wi-Fi 登入網路銀行安全嗎？
網路銀行 App 與網站都有加密連線，風險不高；但如果手機網路可用，用行動網路處理金融相關事務會更單純。重點是確認你用的是官方 App，並且沒有出現憑證錯誤的警告。
手機會自動連上以前連過的 Wi-Fi，有影響嗎？
有人可能架設同名的假熱點，讓手機自動連上。用完公共 Wi-Fi 後，可以在 Wi-Fi 設定裡把它「忘記這個網路」，或關閉「自動加入」。
