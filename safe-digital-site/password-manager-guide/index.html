密碼管理器怎麼選？Apple 密碼、Bitwarden、1Password、Proton Pass 比較

帳號被盜，最常見的原因不是駭客多厲害，而是同一組密碼用在很多網站。只要其中一個網站外洩，其他帳號就跟著被試出來（這叫「撞庫」）。

密碼管理器的用途很單純：幫你替每個網站產生不同的強密碼，並且自動填入，你只要記住一組主密碼。

先看你的裝置組合

你的情況 建議
只用 iPhone、iPad、Mac 先用內建的 Apple「密碼」App
有 Android 或 Windows，想要免費 Bitwarden 或 Proton Pass
願意付費、想要最好上手、全家一起用 1Password

Apple「密碼」App

iOS 18 和 macOS Sequoia 起，Apple 把鑰匙圈獨立成「密碼」App，可以存密碼、通行密鑰（Passkey）、Wi-Fi 密碼，也能產生雙重驗證碼。

  • **優點：**免費、內建、和 Face ID 整合最順，可以建立共享群組和家人分享密碼。
  • **限制：**Windows 要透過 iCloud for Windows 使用，沒有 Android 版。

Bitwarden

  • **優點：**開源，免費版就能在不限數量的裝置間同步不限數量的密碼，這點在免費方案裡很少見。
  • **限制：**介面比較樸素；部分進階功能（例如內建的驗證碼產生器）在付費方案。

1Password

  • **優點：**介面和自動填入體驗做得最完整，有「Watchtower」提醒外洩或重複的密碼，家庭方案管理方便。
  • **限制：**沒有永久免費方案，只有試用期。

Proton Pass

  • **優點：**有免費方案，並內建「隱藏我的信箱」別名功能：註冊網站時產生一個轉寄信箱，不必交出真實 Email，日後被濫發廣告也可以直接停用。
  • **限制：**推出時間比其他幾款晚，部分整合功能仍在追趕。

開始使用的三個步驟

  1. 設定一組長的主密碼：用 4～5 個不相關的詞組合，比短而複雜的密碼更好記也更安全。
  2. 替主帳號開啟雙重驗證。
  3. 從最重要的帳號開始換密碼：Email、Apple / Google 帳號、網路銀行、社群帳號。不需要一天換完。

最重要的是 Email 帳號。大部分網站的「忘記密碼」都會寄到 Email，Email 被盜等於所有帳號都可能被重設。

常見問題

密碼都存在同一個地方，被駭不就全完了？
主流密碼管理器會在你的裝置上先用主密碼加密資料再同步，服務商本身看不到內容。真正的風險在主密碼太弱或被釣魚，所以主密碼要長、要獨一無二，並且開啟雙重驗證。
只用 iPhone 的話需要額外的密碼管理器嗎？
如果你只用 Apple 裝置，內建的「密碼」App 通常就夠用；如果你同時用 Android 手機或需要和不同平台的家人共享，再考慮第三方工具。
