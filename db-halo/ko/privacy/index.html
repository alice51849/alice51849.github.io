설계부터 지키는 개인정보

개인정보 처리방침

dB Halo는 소리를 로컬에서 분석하고 다루는 데이터를 최소화하도록 설계되었습니다. 이 방침은 무엇을 처리하는지, 어떤 정보가 기기에 저장될 수 있는지, 그리고 사용자의 지시에 의해서만 어떤 정보가 App 밖으로 나가는지 정확히 설명합니다.

시행일: 2026년 8월 29일 · 최종 업데이트: 2026년 8월 29일

계정, 광고, 분석, 추적 없음

dB Halo는 계정을 요구하지 않으며 광고, 사용 분석, 추적 또는 타사 SDK를 포함하지 않습니다. Lumi Studio는 dB Halo용 클라우드 서비스를 운영하지 않고, 사용자 프로필을 만들거나 개인정보를 판매하지 않으며, 기기 안의 측정값이나 녹음을 볼 수도 없습니다.

소음계, 스펙트럼, 노출량의 실시간 오디오

소음계, 스펙트럼, RTA, 스펙트로그램 또는 소음 노출량을 사용할 때 마이크 샘플은 수준, 주파수 정보, 노출 추정치를 계산하기 위해 기기 메모리에서 처리됩니다. 원본 오디오는 저장되지 않고 Lumi Studio로 전송되지 않습니다.

수면 이벤트와 명시적으로 시작한 AAC 녹음

수면 모드는 인식된 이벤트 종류, 발생 시각, dB 값만 저장하며 수면 원본 오디오는 보관하지 않습니다. 사용자가 AAC 녹음을 직접 시작한 경우에만 오디오 파일이 생성되고, 삭제하거나 내보낼 때까지 로컬에 남습니다.

사용자가 선택한 사진과 동영상

dB Halo는 Apple PhotosPicker를 사용하므로 전체 사진 보관함이 아니라 사용자가 명시적으로 선택한 사진이나 동영상만 받습니다. 선택 항목은 지원되는 오버레이나 내보내기를 위해 로컬에서 처리되며 Lumi Studio가 업로드하지 않습니다.

HealthKit에는 쓰기만 합니다

건강 권한을 허용하고 노출 내보내기를 선택하면 dB Halo는 환경 소음 노출 샘플을 HealthKit에 기록합니다. App은 건강 데이터를 읽지 않습니다. 권한과 기록은 건강 App 및 iOS 설정에서 관리할 수 있습니다.

로컬 기록, 보정, 무료 사용 횟수

저장한 측정, 이벤트 요약, 보정 프로필, 환경설정, 무료 사용 횟수 기록은 App의 로컬 컨테이너에 보관됩니다. 사용자가 명시적으로 만든 AAC 녹음도 로컬에 있습니다. 이 데이터는 요청한 기능을 제공하는 데만 사용됩니다.

Apple 플랫폼 서비스

Lifetime Pro 구입과 복원은 Apple이 StoreKit으로 처리하며 Lumi Studio는 결제 카드 정보를 받지 않습니다. WatchConnectivity는 페어링된 Apple Watch와 dB Halo 기능에 필요한 데이터만 교환합니다. 위젯과 App Intents는 App의 공유 로컬 컨테이너를 사용합니다. 이러한 시스템 서비스가 Lumi Studio 클라우드 계정을 만들지는 않습니다.

사용자가 지시하는 파일과 공유

CSV, PDF, AAC, 사진, 동영상 결과물은 사용자가 요청할 때만 만들어집니다. 시스템 파일 또는 공유 화면에서 저장 위치나 수신자를 직접 선택합니다. dB Halo는 자동 업로드하지 않으며, 위치를 선택한 뒤의 사본은 해당 서비스 제공자나 수신자가 관리합니다.

지원 이메일 예외

지원팀에 이메일을 보내면 이메일 주소, 메시지, 첨부 파일이 관련 이메일 제공자를 통해 전송되고, Lumi Studio는 답변, 보안 유지, 요청 기록 목적으로만 이를 받습니다. 지원 메일은 해당 목적이나 법적 의무에 합리적으로 필요한 기간만 보관한 뒤 의무에 따라 삭제하거나 보존합니다. 필요하지 않은 민감한 오디오, 미디어, 건강 정보는 보내지 마세요.

보관과 삭제

저장한 측정과 명시적 녹음은 dB Halo의 해당 기능에서 삭제할 수 있습니다. App을 삭제하면 남은 App 컨테이너 데이터도 삭제되지만, 사용자와 Apple이 관리하는 일반 기기 백업은 제외됩니다. 내보낸 파일은 선택한 위치에서 삭제하고, 건강 기록은 건강 App에서 관리하며, Watch App을 제거해 시계의 로컬 데이터를 지울 수 있습니다. 법적 보관 의무가 없다면 지원 메일 삭제도 요청할 수 있습니다.

아동, 안전, 법적 한계

dB Halo는 아동의 개인정보를 수집하도록 설계되지 않았습니다. 계정이 없으므로 아동이나 가족이 사용할 때도 권한과 공유는 기기 소유자가 결정합니다. 측정값은 참고 정보이며 의료 조언, 청력 진단, 인증 소음 측정, 산업안전 규정, 전문가 또는 법적으로 필요한 보정 장비를 대신하지 않습니다.

시행일과 변경

이 방침은 2026년 8월 29일부터 시행되며 같은 날 최종 업데이트되었습니다. dB Halo의 데이터 처리 방식이 바뀌면 사전 고지가 필요한 지역에서는 변경된 방식이 적용되기 전에 이 페이지를 업데이트합니다.
