개인정보를 지키는 소리 인식

주변 소리를 한눈에 이해하세요

dB Halo는 iPhone, iPad, Apple Watch를 이해하기 쉬운 소음 수준 도구로 바꿔 줍니다. 현재 크기를 빠르게 보고, 실시간 주파수를 자세히 살피며, 소음 노출을 추정하고 유용한 기록을 남길 수 있습니다. 모든 분석은 기기에서 이루어집니다.

  • 계정 불필요
  • 광고 및 추적 없음
  • 기기 내 오디오 처리
  • Lifetime Pro 1회 구매
64dB

dB Halo의 기능

처음에는 간단하게, 필요할 때는 자세하게

소음계와 Halo

명확한 Halo로 현재, 최저, 평균, 최고, 피크 수준을 확인하고 가중치, LAeq, 쉬운 설명도 함께 볼 수 있습니다.

스펙트럼, RTA, 스펙트로그램

활성 분석을 끊지 않고 동기화된 FFT, 옥타브 대역 RTA, 스펙트로그램으로 주파수별 에너지를 살펴봅니다.

소음 노출량

추정 노출량, 남은 시간, NIOSH 또는 OSHA 지침을 확인합니다. 결과는 참고 정보이며 작업장 규정 준수 판정이 아닙니다.

수면 소리 이벤트

인식된 이벤트 종류, 발생 시각, dB 값을 기기에 기록합니다. 수면 모드는 원본 오디오를 저장하지 않습니다.

기록과 내보내기

측정 기록과 보정 프로필을 로컬에 보관하고, 사용자가 요청할 때 CSV, PDF, AAC, 사진 또는 동영상 결과물을 만듭니다.

Watch, 위젯, 단축어

Apple Watch 전용 경험, 위젯, App Intents를 사용하며, 페어링된 기기는 각 동작에 필요한 로컬 데이터만 주고받습니다.

01

빠른 시작

  1. ‘소음계’를 열고 iOS가 요청하면 마이크 접근을 허용합니다.
  2. 기기가 가려지거나 옷에 쓸리지 않는 곳에 놓고 ‘시작’을 탭합니다.
  3. Halo와 현재 dB 값으로 빠르게 확인하고, 더 자세히 보려면 ‘스펙트럼’ 또는 ‘노출량’을 엽니다.
  4. 화면을 떠나기 전에 ‘중지’를 탭하고, 결과를 보관하려면 ‘기록’에 저장합니다.

02

권한은 언제나 사용자가 관리합니다

  • 소리 측정과 분석에는 마이크가 필요합니다. 소음계, 스펙트럼, 노출량의 원본 오디오는 메모리에서만 처리되고 저장되지 않습니다.
  • 사진과 동영상은 시스템 사진 선택기에서 특정 항목을 고른 뒤에만 접근하며, dB Halo는 선택한 항목만 기기에서 처리합니다.
  • 건강 접근은 선택 사항입니다. 허용해도 dB Halo는 환경 소음 노출 샘플만 기록하고 건강 데이터는 읽지 않습니다.

03

Lifetime Pro와 구입 복원

Lifetime Pro는 구독이 아닌 비소모성 1회 구매입니다. 확인하기 전에 App Store가 지역별 가격을 표시합니다. 이전 구입을 복원하려면 dB Halo → ‘설정’ → ‘Lifetime Pro’ → ‘구입 복원’을 열고 처음 구입한 Apple Account를 사용하세요.

04

문제 해결

  • 값이 보이지 않을 때: iOS 설정에서 마이크 권한을 확인하고, 의도하지 않은 오디오 장치를 분리하며, 다른 App이 마이크를 사용 중인지 확인하세요.
  • 값이 예상과 다를 때: 마이크 주변의 케이스나 가림을 제거하고, 손으로 만지는 소리를 피하며, 입력과 보정 프로필을 확인하세요.
  • Watch나 위젯이 오래된 값을 보일 때: iPhone과 Watch를 가까이 페어링한 상태로 두고 iPhone에서 dB Halo를 한 번 연 뒤 시스템 갱신을 잠시 기다리세요.
  • 구입이 복원되지 않을 때: 네트워크 연결과 원래 Apple Account를 확인하고 Lifetime Pro에서 ‘구입 복원’을 다시 실행하세요.

중요한 측정 안내

도움이 되는 추정치이며 인증 장비가 아닙니다

휴대전화와 시계의 마이크는 모델, 위치, 케이스, 환경, 보정에 따라 달라집니다. dB Halo는 일상적인 인식과 개인 기록에 유용하지만 인증 소음계가 아니며, 의료 조언, 청력 평가, 산업위생 측정 또는 법적으로 요구되는 보정 장비를 대신하지 않습니다.
